# Local Workspace Instruction For Other Codex Threads

Please stop using Google Drive as the active development/workspace folder for this project.

Use an accessible local folder under:

```text
/Users/meghamsh/Coding Projects/<project-name>
```

Use Google Drive only as a backup/mirror destination when explicitly requested, not as the live working directory.

For app data/cache/export paths, prefer local user folders such as:

```text
~/Documents/Coding Projects/<app-name>/data
~/Documents/Coding Projects/<app-name>/attachments
~/Documents/Coding Projects/<app-name>/exports
~/Documents/Coding Projects/<app-name>/sync
```

Apply this convention to:

- AOE2 Hotkey Editor
- Monopoly
- Sack app
- Easylab Lab Notebook

If a project already exists only in Google Drive, copy it once into `/Users/meghamsh/Coding Projects/<project-name>` and work from that local copy. After meaningful changes, mirror changed source files back to Google Drive only if asked.
